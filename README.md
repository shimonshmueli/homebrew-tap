# Shimonshmueli Tap

## How do I install these formulae?

`brew install shimonshmueli/tap/<formula>`

Or `brew tap shimonshmueli/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "shimonshmueli/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
